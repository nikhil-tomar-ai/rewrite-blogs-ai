# Security Policy

## Privacy & Local Execution Guarantee

SparkyAI is designed to be **100% local-first**. By default:
* No prompt data, CSV content, or generated results leave your machine.
* No telemetry or analytics tracking is transmitted.
* Local database storage (`./data`) and storage directories (`./storage`) are kept on your local filesystem.

## Reporting a Vulnerability

If you discover a security vulnerability in SparkyAI:

1. Do NOT open a public issue on GitHub.
2. Email security details privately to the project maintainers.
3. Include detailed steps to reproduce the vulnerability.

We will review reports promptly and release patches for any confirmed security vulnerabilities.
